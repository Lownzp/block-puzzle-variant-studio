# 识别评测指标说明

## 评测原则

动作识别优先判断“语义是否正确”，时间只作为辅助指标。程序选择的放置后帧可以和人工真值帧不同，只要动作语义和棋盘状态等价，就不应被时间偏移直接判错。

## 主指标

| 指标 | 含义 |
|---|---|
| `precision` | 预测动作中成功匹配真值动作的比例 |
| `recall` | 真值动作中被预测动作覆盖的比例 |
| `semanticActionAccuracy` | 已匹配动作里，来源槽位、形状、落点、消除状态同时正确的比例 |
| `shapeAccuracy` | 已匹配动作里，方块形状正确的比例 |
| `targetAccuracy` | 已匹配动作里，棋盘落点正确的比例 |
| `clearAccuracy` | 已匹配动作里，消除开关/消除模式正确的比例 |
| `stateEquivalentRate` | 预测动作的放置后棋盘，与真值的放置后或消除后棋盘等价的比例 |
| `legalMoveRate` | 预测动作是否都完整落在棋盘内 |

## 辅助时间指标

| 指标 | 含义 |
|---|---|
| `withinActionWindow` | 预测时间是否落在真值动作区间内。真值只有单点时间时，会给一个小窗口容忍稳定帧差异 |
| `timeMae` | 预测时间和真值执行时间的平均绝对误差 |
| `withinTwoFrames` | 是否落在真值时间前后两帧内。该指标只表示时间边界精度，不代表动作语义对错 |

## 对齐机制

动作序列仍使用单调动态规划对齐，但 pair cost 改为语义优先：

- 来源槽位、形状、落点、消除都正确时，时间误差只产生很小惩罚。
- 形状和落点正确但槽位/消除有差异时，仍优先配成同一个动作，再由细分指标体现错误。
- 形状或落点不一致时，才使用更高惩罚。

这样可以避免程序选中“同一个动作的不同稳定帧”时，被错误地记为 false positive 或 missed。
