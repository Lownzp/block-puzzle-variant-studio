# 托盘专项真值与逐槽评测 — 实现计划

## Overview

为托盘形状识别 `_bottom_groups` 建立 component 级真值与评测：在现有复核界面标注每个动作"落子前"三个槽的形状（复用现成格子编辑器），随现有保存流程落盘，再用逐槽评测脚本判定 DEV-008 短板是"托盘没检出"还是"拆错"。设计见 `docs/托盘专项真值与评测设计.md`。

## Current State

- `_bottom_groups(frame, board, rows, cols, material_profile="unknown", refine_grid=False)`（`timeline_analyzer.py:1185` 附近）：读三槽形状，`refine_grid=True` 时输出 `score`/`connected`（C1，flag `tray_shape_grid_refine_v1`）。
- 复核界面：`renderAnnotationStudio` 注入 `#analysisResult`；每步编辑器 `workbenchHtml(action,index)`（`annotation-studio.js:468`）含槽位/形状/落点/消除。
- 形状编辑器现成：`shapeGrid()`（`index.html:736`）、`toggleActionCell()`（`annotation-studio.js:1405`，点选→`[{row,col}]` 归一化到左上角）、样式 `.shape-grid/.shape-cell`（`index.html:40-42`）；离散选择 `segmentHtml()`（`annotation-studio.js:424`）；"一对象挂多形状"范式 `referenceShapeGrid()`（`annotation-studio.js:562`）。
- 保存：`confirmActions()` → `POST /api/video/confirm-actions` → `handle_video_confirm_actions()`（`variant_bridge.py:3106`）把 `payload.actions` **原样**写进 `识别草稿.json` 的 `reviewActions`（3128）和版本文件（3135）。
- 重跑取数模式（评测脚本复用）：`scripts/reanalyze_truth_set.py` — `latest_truth_tasks()`、`board = initial_draft(task)["board"]`、视频 `task/"source.mp4"`、`--only DEV-...`。

## Desired End State

- 复核界面每步多一块"落子前托盘"面板，可标三槽"空/形状"，保存后 `识别草稿.json` 的 `reviewActions[i].trayBefore` 落盘。
- `scripts/evaluate_tray_recognition.py` 能对 `--only DEV-008 DEV-004 DEV-011` 跑出逐槽指标（检出率/形状正确率/误检率）+ refine 专项 + 「动作漏检×托盘检出」交叉表，baseline vs refine 两列。
- `tests/test_tray_recognition.py` 覆盖纯逻辑，`python -m unittest tests.test_tray_recognition` 通过。

## Key Discoveries

- **后端零改动**：confirm 原样保存 action 额外字段到 `reviewActions`（`variant_bridge.py:3128,3135`）。评测从 `识别草稿.json.reviewActions[i].trayBefore` 读（**不是**从 `确定性回放真值.json` 的重建 steps 读）。
- **board/grid**：`initial_draft(task)["board"]`（像素 x,y,w,h）；rows/cols 从 `确定性回放真值.json` 的 `grid` 或 draft 读（参照 `truth_benchmark.evaluate_task` 的 rows/cols 兜底逻辑）。
- **归一化一致**：`toggleActionCell` 把 shape 归一化到左上角原点；托盘形状比对必须同样归一化后、顺序无关地比较。
- **frameIndex**：标注时取当前 Video.js 播放器帧（`studio.player`），写入 `trayBefore.frameIndex`；评测按此帧读像素。

## What We're NOT Doing

- 不标噪点/细缝/遮挡/拾取前后多状态（只标"落子前"单帧三槽形状）。
- 不做独立托盘标注页；不动 vis-timeline；不重做棋盘落点逻辑。
- 不改后端 confirm 逻辑（除非 Phase 2 手测发现 trayBefore 未落盘）。
- 不扩到 8 条/全库。

## Implementation Approach

先做**评测脚本 + 单测**（不依赖 UI，用手造 trayBefore 即可验证），再做**前端标注面板**，最后**标 3 条 + 跑评测出结论**。

## Phase 1: 逐槽评测脚本 + 单测

### Overview
不依赖前端，先让"托盘尺子"可跑、可测。

### Changes Required

#### 1. 纯逻辑 + 脚本
**File**: `scripts/evaluate_tray_recognition.py`（新增）

纯函数（供单测）：
```python
def normalize_cells(cells):
    """cells: iterable of (row,col) or {"row","col"}; -> frozenset 归一化到左上角原点。"""
    pts = [(int(c["row"]), int(c["col"])) if isinstance(c, dict) else (int(c[0]), int(c[1])) for c in cells]
    if not pts:
        return frozenset()
    r0, c0 = min(r for r, _ in pts), min(c for _, c in pts)
    return frozenset((r - r0, c - c0) for r, c in pts)

def compare_slot(truth_slot, predicted_group):
    """-> 'detected_exact' | 'detected_wrong' | 'missed' | 'false' | 'correct_empty'"""
    occupied = bool(truth_slot.get("occupied"))
    pred = predicted_group is not None
    if occupied and pred:
        same = normalize_cells(truth_slot.get("shape") or []) == normalize_cells((predicted_group or {}).get("shape") or [])
        return "detected_exact" if same else "detected_wrong"
    if occupied and not pred:
        return "missed"
    if not occupied and pred:
        return "false"
    return "correct_empty"

def aggregate_outcomes(outcomes):
    """outcomes: list[str] -> {slotDetectionRate, slotShapeExactRate, falseSlotRate, counts...}"""
    occ = [o for o in outcomes if o in ("detected_exact", "detected_wrong", "missed")]
    detected = [o for o in occ if o.startswith("detected")]
    empty = [o for o in outcomes if o in ("false", "correct_empty")]
    return {
        "occupiedSlots": len(occ),
        "detected": len(detected),
        "slotDetectionRate": round(len(detected) / max(1, len(occ)), 4),
        "slotShapeExactRate": round(sum(o == "detected_exact" for o in detected) / max(1, len(detected)), 4),
        "falseSlotRate": round(sum(o == "false" for o in empty) / max(1, len(empty)), 4),
    }
```

脚本主流程（复用 reanalyze 模式）：
- `latest_truth_tasks()` + `--only`；`board = initial_draft(task)["board"]`；video `task/"source.mp4"`；rows/cols 从 truth 读。
- 读 `识别草稿.json` 的 `reviewActions`，取含 `trayBefore` 的动作。
- 对每个 `trayBefore.frameIndex`：`cv2` 读该帧，`_bottom_groups(frame, board, rows, cols, refine_grid=False)` 和 `=True` 各跑一次，逐槽 `compare_slot`，`aggregate_outcomes` 汇总 baseline/refine 两列。
- refine 专项：统计 `connected is False→修复` 次数、`score` 分布。
- 交叉表：每动作 `sourceSlot` 槽的 outcome +（可选）该动作动作级是否漏检（若传 `--prediction-dir` 则关联 `truth_benchmark`）。
- 输出 JSON + Markdown。

#### 2. 单测
**File**: `tests/test_tray_recognition.py`（新增）
- `normalize_cells`：平移不变、顺序无关、空集。
- `compare_slot`：五种 outcome 各一例（含"形状不同→detected_wrong"）。
- `aggregate_outcomes`：混合样例的三率计算。
